# Аналитика клиентской базы интернет-магазина

Комплексный аналитический проект по данным онлайн-магазина: от очистки сырых транзакций до сегментации клиентов, прогноза оттока и расчёта их пожизненной ценности. Цель проекта показать полный цикл работы аналитика, где каждый метод отвечает на конкретный бизнес-вопрос, а результаты сходятся в единые рекомендации по работе с клиентской базой.

## Данные

Использован публичный датасет Online Retail (UCI Machine Learning Repository) — транзакции британского онлайн-магазина подарков за период с декабря 2010 по декабрь 2011 года, около 541 тысячи строк. Каждая строка это позиция в заказе: номер счёта, код и описание товара, количество, дата, цена и идентификатор клиента.

## Ход работы и результаты

### Очистка данных

Сырые данные содержали типичные для розницы проблемы, которые пришлось обработать осознанно, а не механически. Около четверти строк не имели идентификатора клиента, возвраты были закодированы отрицательным количеством, отменённые заказы отмечались буквой C в номере счёта, встречались нулевые и отрицательные цены. После обработки всех этих случаев в работе осталось 392 692 строки из исходных 541 909. Каждое решение об удалении обосновано, а не сделано вслепую, поскольку от чистоты данных зависит корректность всех дальнейших расчётов.

### RFM-сегментация

Клиентская база разбита на сегменты по трём осям: давность последней покупки (Recency), частота покупок (Frequency) и суммарные траты (Monetary). Каждому клиенту присвоены баллы по квинтилям и итоговый сегмент, от чемпионов до потерянных. Главный вывод оказался показательным: примерно 8 процентов клиентов из сегмента чемпионов приносят около 44 процентов всей выручки. Выручка сильно сконцентрирована в узкой группе, и это определяет приоритеты в работе с базой.

### ABC/XYZ-анализ ассортимента

Товары разложены по двум измерениям. ABC-анализ ранжирует их по вкладу в выручку через накопленную долю: 783 товара класса A дают около 80 процентов выручки, тогда как 1958 товаров класса C приносят лишь несколько процентов при том, что составляют больше половины ассортимента. XYZ-анализ оценивает стабильность спроса через коэффициент вариации помесячных продаж. Пересечение двух измерений даёт матрицу из девяти групп, которая подсказывает, какие товары держать на складе в первую очередь, а какие являются кандидатами на вывод из ассортимента.

### Кластеризация

Помимо ручной сегментации по правилам применён алгоритм K-means, который находит группы в данных сам, без заданных порогов. Признаки предварительно стандартизированы, оптимальное число кластеров выбрано методом локтя и составило четыре. Сравнение машинных кластеров с ручными RFM-сегментами дало главный инсайт этой части: алгоритм выделил микросегмент из тринадцати клиентов с экстремально высокими тратами и частотой, своего рода китов, которых правила RFM растворили в общей массе. Там, где экспертные правила видели обычных клиентов, кластеризация распознала отдельную ценную группу.

### A/B-тест

Поскольку исходные данные не содержат реального эксперимента, A/B-тест смоделирован для демонстрации методики. Проверялась гипотеза о том, что скидка повышает возврат клиентов из сегмента риска. Группы разделены случайно, исходы сгенерированы по заданным вероятностям, значимость различия проверена критерием хи-квадрат. Метод выбран потому, что метрика бинарная, а сравниваются доли двух групп. Полученное p-value около 0.02 ниже порога 0.05, то есть различие признано статистически значимым. Отдельно в проекте разобрана разница между статистической и практической значимостью, а также влияние размера выборки на мощность теста.

### Прогноз оттока

Построена модель классификации, предсказывающая уход клиента. Целевая метка создана по правилу давности последней покупки, при этом сама Recency сознательно исключена из признаков, чтобы избежать утечки целевой переменной. Данные разделены на обучающую и тестовую выборки со стратификацией, учтён дисбаланс классов. Сравнивались логистическая регрессия и случайный лес, и выбор модели делался не по общей точности, которая на несбалансированных классах обманчива, а по полноте на классе оттока: для задачи удержания важнее не пропустить уходящего клиента. Логистическая регрессия дала полноту около 0.92. Анализ важности признаков показал, что сумма трат предсказывает отток заметно сильнее, чем частота покупок.

### Юнит-экономика и LTV

Пожизненная ценность клиента рассчитана на трёх уровнях глубины. Исторический LTV это уже накопленная выручка, прогнозный учитывает среднее время жизни клиента, оценённое через уровень оттока, а дисконтированный вводит поправку на то, что деньги в будущем стоят меньше, чем сегодня, по логике чистой приведённой стоимости. После дисконтирования ценность клиента-чемпиона составила около 43 тысяч против примерно 880 у потерянного клиента, разница почти в пятьдесят раз. Сопоставление дисконтированного LTV со стоимостью привлечения дало отношение LTV к CAC по сегментам: от 21.6 у чемпионов до 0.44 у потерянных при здоровом пороге около 3 к 1. Это переводит анализ на язык окупаемости и показывает, привлечение каких клиентов выгодно, а каких убыточно.

## Общий вывод

Все части проекта сходятся в одну историю вокруг сегмента риска. RFM выделил этих клиентов как ценных, но уходящих. Модель оттока предсказывает их уход заранее. Смоделированный A/B-тест показал, что скидка способна их вернуть. А расчёт юнит-экономики доказал, что удерживать их выгодно, поскольку их ценность заметно превышает стоимость привлечения. Отсюда главная рекомендация: сосредоточить усилия по удержанию именно на клиентах из зоны риска, а привлечение таргетировать на профили, похожие на самые окупаемые сегменты.

## Стек

Python, pandas, numpy, scikit-learn, scipy, matplotlib. Работа велась в Jupyter Notebook.

## Структура репозитория

Проект разбит по этапам, каждый в отдельном ноутбуке в логическом порядке: очистка данных, RFM-анализ, ABC/XYZ-анализ, кластеризация, A/B-тест, классификация оттока, юнит-экономика. Исходные данные лежат в файле Online_Retail.xlsx, промежуточные результаты между этапами сохранены в файлах формата pkl и csv, чтобы каждый ноутбук можно было запустить, не пересчитывая предыдущие.

## Оговорки

Проект носит учебно-демонстрационный характер. A/B-тест смоделирован, стоимость привлечения клиента и ставка дисконтирования взяты как разумные предположения, а среднее время жизни клиента оценено единым для всей базы, а не по каждому сегменту отдельно. Эти упрощения не влияют на демонстрируемую методику, но их стоит учитывать при интерпретации конкретных чисел.
